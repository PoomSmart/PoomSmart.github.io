Compatibility

  • Compatible with iOS 9.0 +

Description

  • Removes screen recording resolution cap (1600x1600 or 1920x1920) from ReplayKit-based applications, including SpringBoard.

    Tweak version of defaults write replayd RPFullResCapture -bool 1

Changelog

  • 2.0.1: Fixed screen recording not starting

  • 2.0.0: 

    Added a Settings page to turn the tweak on or off

    Added optional 120 FPS recording on displays that support it. Playback still follows how often the screen updates

    Added optional HEVC recording on devices that support it

    Added experimental HDR10 recording on displays that support it. The picture may look too bright
